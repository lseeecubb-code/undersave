Room map editor

Click Player spawn point to place a named spawn. A door uses the named spawn ID in its destination room. Spawn dots are cyan.

Choose Sprite instance, select a saved pixel sprite, then click the room to place it. Drag sprites like other objects.

Resize the floor, doors, collision boxes, enemy triggers, and dialogue areas from their blue corner handle.

Enemy editor

Enemy data
Custom behavior returns an attack pattern ID or an index from the enemy's attacks list. Map encounters use the selected enemy ID. Natural encounters are selected only from monsters whose Natural encounters flag is enabled.
